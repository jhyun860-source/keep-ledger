# Claude Code Instructions

Read and follow [`AGENTS.md`](./AGENTS.md) before changing this repository. It is the shared implementation contract for Claude Code and other AI development tools.

Use the following command to validate a change before committing it:

```bash
pnpm run verify
```

When changing the data model, create and commit a Drizzle SQL migration. Do not hand-edit the generated migration metadata. Keep the existing Korean product language and VELLUM hospitality-led design system intact.
